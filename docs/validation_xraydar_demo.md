# X-Raydar Backend Validation

Validation date: 2026-06-13

## What Was Tested

The app pipeline was pointed at the real local X-Raydar evidence service:

```powershell
uv run python scripts/run_xraydar_service.py --backend-dir outputs/xraydar-cv --device cpu --port 9000
uv run python scripts/validate_xraydar_demo.py --evidence-url http://127.0.0.1:9000/analyze --timeout-seconds 300 --top-k 7 --positive-threshold 0.5
```

This validates the same app path used by the Gradio app:

```text
DICOM -> app image loader -> HTTPChestEvidenceModel -> X-Raydar service -> EvidenceBundle
```

## Dataset

Source: `gmontana/xraydar-cv` upstream `demo_data`.

The demo set contains 10 DICOM cases:

- 6 labeled abnormal/non-normal cases
- 4 normal cases

## Result

| Metric | Result |
|---|---:|
| Total cases | 10 |
| Passed cases | 10 |
| Labeled cases | 6 |
| Labeled cases with expected label in top-7 | 6 |
| Normal cases | 4 |
| Normal cases with no score >= 0.5 | 4 |

## Running App Smoke Test

The same backend was also exercised through the running Gradio app:

```powershell
uv run python scripts/smoke_gradio_xraydar.py --app-url http://127.0.0.1:7860
```

Result on the upstream scoliosis demo DICOM:

- Top finding: `scoliosis`
- Score: `0.993`
- Source: `xraydar-cv`
- Model note: `Evidence generated by local X-Raydar CV backend.`

For full-stack verification with a live vLLM tutor, run:

```powershell
uv run python scripts/smoke_gradio_xraydar.py --app-url http://127.0.0.1:7860 --require-live-tutor
```

That additionally fails unless the tutor provider is `nemotron-tutor:openai` and no fallback tutor text is present.

Verified full-stack result on 2026-06-13:

- Evidence backend: local X-Raydar service
- Tutor backend: vLLM serving `nvidia/NVIDIA-Nemotron-3-Nano-4B-FP8`
- Top finding: `scoliosis`
- Score: `0.993`
- Source: `xraydar-cv`
- Tutor provider: `nemotron-tutor:openai`
- Result: passed

## Notes

- The local environment installed a CPU-only PyTorch wheel, so validation ran on CPU.
- This is a smoke/contract validation, not a clinical validation.
- It proves that the app can run against a real CXR classifier backend and that outputs match the upstream demo labels on the included demo cases.
- For stronger evidence before submission, repeat this harness on VinDr-CXR or another labeled external dataset.
