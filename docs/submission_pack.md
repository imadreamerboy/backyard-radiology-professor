# Submission pack

## Demo sequence

1. Open a real public chest radiograph or a multi-image DX study.
2. Demonstrate window/level, invert, ruler, filmstrip, and two-up viewing.
3. Commit a natural-language blind interpretation.
4. Show live X-Raydar, localizer, model-swap, and professor progress.
5. Inspect independently attributed evidence and manipulate individual regions.
6. Ask the professor to explain a missed concept, compare views, build a differential, and quiz the trainee.
7. Export the session with model identities, timings, chat, and region state.
