# Validation artifacts

These files are generated by the real backend acceptance scripts and checked in
as reproducibility evidence:

- `local-golden-cases.json`: all labeled public cases through X-Raydar,
  MedGemma localization, and the MedGemma professor.
- `local-runtime-benchmark.json`: cold/warm latency, throughput, model
  revisions, and GPU memory.
- `space-golden-cases.json`: the same golden suite against the public Space.
- `space-runtime-benchmark.json`: the same benchmark against the public Space.

An artifact is added only after the corresponding environment passes without
mock or fallback model output.
